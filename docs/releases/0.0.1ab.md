# Iberia Smart Disc 0.0.1ab · BETA

Primera versión pública para Windows 10 (1903 o posterior) y Windows 11.
Es una BETA: puede contener errores y todavía necesita pruebas con lectores
y discos físicos de distintos equipos.

- Abre tus juegos de Steam, GOG, Epic Games o una carpeta elegida al insertar
  un disco de Iberia Custom DVDs con `iberia-disc.json`.
- Instalación para tu usuario, inicio opcional con Windows y desinstalación
  desde el programa o Configuración → Aplicaciones.
- La versión `0.0.1ab · BETA` aparece en la ventana principal, el instalador
  y el icono de la bandeja.
- Sin cuentas, publicidad, telemetría ni conexión a Internet.

## Instalar

1. Descarga `IberiaSmartDisc.exe` de los archivos de esta versión o desde
   [la página oficial](https://iberiacustomdvds.es/launcher).
2. Abre el archivo y pulsa **Instalar**. No requiere administrador.
3. Mete tu disco; la primera vez puedes elegir qué instalación del juego usar.

El programa no incluye juegos ni sus licencias. Para actualizar, abre la
versión nueva; conserva la configuración y los juegos recordados.

## Verificar la descarga

El ejecutable lo compila GitHub Actions. Se publica con su archivo
`IberiaSmartDisc.exe.sha256`, una atestación de procedencia y la licencia de
uso personal no comercial.

```powershell
Get-FileHash .\IberiaSmartDisc.exe -Algorithm SHA256
gh attestation verify IberiaSmartDisc.exe -R Davidvx98/iberia-smart-disc
```

El ejecutable todavía no tiene firma Authenticode: SmartScreen puede mostrar
un aviso. Windows 11 con Smart App Control activado puede impedir ejecutarlo.
Consulta [SECURITY.md](https://github.com/Davidvx98/iberia-smart-disc/blob/main/SECURITY.md)
antes de abrirlo y descarga únicamente desde los enlaces oficiales.

Puedes comunicar fallos no sensibles en
[Issues](https://github.com/Davidvx98/iberia-smart-disc/issues).
